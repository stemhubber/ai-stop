# Webilo user journey action plan

This plan converts the first usability test into measurable product work. Progress is derived from real business data; it is not a points or badge system.

## Completed in this iteration

- [x] Replace the generic Overview entry point with a focused **Today** screen.
- [x] Show one recommended next action instead of presenting every tool at once.
- [x] Derive a six-step launch path from the business profile, offers, enabled modules, websites, publishing state, and customer activity.
- [x] Add a persistent **Guide me / I know what I need** preference.
- [x] Keep all tools available to advanced users.
- [x] Replace the mobile tab rail with four stable destinations: Today, Sell, Customers, and More.
- [x] Add mobile Sell and More hubs so every destination has a working action.
- [x] Increase mobile form controls to at least 16px to prevent browser focus zoom.
- [x] Contain workspace overflow on mobile.
- [x] Replace remaining purple interaction accents in the business workspace with the Webilo teal system.
- [x] Add tests for launch-path derivation.

## Next validation cycle

- [ ] Run five first-time users through business creation without coaching.
- [ ] Measure time to first offer, website draft, publish, and customer action.
- [ ] Record repeated tab switching and abandoned launch steps.
- [ ] Confirm users can identify their next action within five seconds.
- [ ] Compare guided and advanced mode usage after the first session.
- [ ] Add event analytics only after event names and privacy requirements are agreed.

## Success criteria

- At least 80% of first-time users identify the next step without assistance.
- Median time from business creation to first offer is below five minutes.
- Mobile sessions do not trigger input-focus zoom or horizontal page dragging.
- Every empty state and recommended action opens the tool required to complete it.
- Advanced users can reach any operational tool in two taps or fewer on mobile.
